# Sloppy Human: Engineering Authenticity & Human Touch

This specialist skill injects authentic engineering craft into synthetic AI outputs. It replaces generic filler with concrete technical realism, realistic operating states, and human-crafted microcopy.

---

## 1. Concrete Domain Nouns vs Generic Placeholders

Synthetic code is plagued by generic nouns: `item1`, `card title`, `user name`, `data description`.

### Engineering Realism Protocol:
Always ground UI with specific domain nouns:
- **Cloud Infrastructure**: `us-east-1a`, `k8s-worker-pool-02`, `10.0.4.128:5432`, `p99 latency 14.2ms`.
- **Developer Tools**: `git merge origin/main --ff-only`, `HTTP 429 Rate Limit Exceeded`, `commit 8eebb36`.
- **Fintech & Billing**: `ACH Payout #849201`, `Stripe Connect webhook verified`, `Net 30 invoice`.
- **Telemetry & Tracing**: `span_id: 0x9f4a1`, `trace_flags: 01`, `db.query: SELECT id FROM users WHERE org_id = $1`.

---

## 2. Authentic Chrome Headers (`REAL_WORLD_CHROME_MISSING`)

Miniature floating windows without context look synthetic. Use authentic window headers:
- Include genuine macOS traffic light controls (`w-3 h-3 rounded-full bg-neutral-700/80`) or clean tab bar navigation.
- Add an authentic monospace breadcrumb or path tag: `~/Developer/repo/packages/core/index.ts`.
- Ground status indicators: `<span className="inline-block w-2 h-2 rounded-full bg-emerald-400 mr-2" /> Connected`.

---

## 3. Human Pacing & Grounded Error States

AI generators only design pristine happy paths. Human software engineers design for realistic boundaries:
- **Empty States**: Never show a raw blank box. Provide a quiet, helpful affordance with a single direct action.
- **Degraded States**: Show realistic reconnecting states (`Attempting reconnect 2 of 5...`) with timestamped logs.
- **Action Confirmation**: Provide reversible destructive actions (`Archive Project` with 10-second undo toast) rather than sudden unannounced changes.
