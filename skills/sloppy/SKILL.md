# Sloppy: The AI Slop UI Fixer & Unified Design Engine

AI agents routinely generate "AI UI Slop":
- Unwarranted purple/indigo gradients and sparkle icons on generic features.
- Boxed card monotony: wrapping every element in identical `rounded-xl border p-6` cards with flat hierarchy.
- Floating windows: shrinking an entire application into a tiny card with uniform air on all 4 sides.
- Word overload: filling every row with fake numbers and text instead of disciplined word budgeting.
- Unearned animations: spinning, bouncing, and sudden content swaps without cause-and-effect transitions.

Sloppy eliminates AI slop by unifying 7 top-tier component ecosystems (Stageshow, shadcn/ui, Motion Primitives, Magic UI, React Bits, Kokonut UI, and Animate UI) with an automated surgical AST auto-fixer, 10 synthesized master archetypes, a 10-point Craft Rubric grading engine, a Model Context Protocol (MCP) server, and a developer CLI.

Sloppy unifies 700+ components and 73+ gold patterns into a single anti-slop catalog:

1. **Stageshow (`stageshow`)**: Grounded product framing, cursor choreography, anti-slop primitives (`Stage`, `Window`, `Act`, `Ease`, `Bar`), and 73+ gold product patterns.

3. **Motion Primitives (`motion-primitives`)**: Physics-based micro-interactions (Morphing Dialog, Sliding Number, Expandable Tabs) with disciplined damping.
4. **Magic UI (`magicui`)**: Restrained marketing hero elements (max 1 beam/glow, opacity < 0.15, zero purple sparkle combos).
5. **React Bits (`react-bits`)**: Ambient canvas shaders and kinetic typography with low particle counts and strict text contrast.
6. **Kokonut UI (`kokonutui`)**: Modern AI prompt composers, agent execution lanes, and tool approval cards that eliminate AI sparkle clichés.
7. **Animate UI (`animate-ui`)**: Fluid physics, staggered reveals, and clean transition variants (150-300ms durations).

## The 10-Point Craft Rubric & Certification

Sloppy grades every UI component across 10 distinct craft dimensions (0 to 10 points each, 100 points total):
1. **Surface Elevation & Grounding (0-10)**: Grounded surface steps (0, 1, 2, 3), zero floating unanchored cards.
2. **Word Budget & Text Restraint (0-10)**: 3 to 7 real strings, placeholder bars for background copy.
3. **Motion Intentionality & Easing (0-10)**: Cause-driven transitions with settled physical easing; zero unearned bounces.
4. **Visual Focal Hierarchy (0-10)**: Unmistakable dominant focal node, clear primary/secondary weight.
5. **Icon Authenticity (0-10)**: Zero decorative sparkles or magic wands on generic features.
6. **Monochromatic Restraint (0-10)**: Monochromatic neutral ground, single intentional accent color for true signals.
7. **Framing & Bleeding Rules (0-10)**: Covers >= 66% of stage, bleeds secondary panels off stage frame.
8. **Density & Spacing Rhythm (0-10)**: Tight information density, disciplined padding.
9. **Real-World Chrome Integrity (0-10)**: Authentic window headers, realistic monospace tags, zero fake AI marketing labels.
10. **Semantic Accessibility & Contrast (0-10)**: High contrast ratio and accessible typographic foundations.

Grade scale: **A+ (95-100)**, **A (90-94)**, **B (80-89)**, **C (70-79)**, **D (50-69)**, **F (<50)**.

## The Sloppy MCP Server Tools

When working in an agentic coding environment (Antigravity, Claude Code, Cursor, OpenHands), you have direct access to the `sloppy` MCP tools:

- `sloppy_evaluate_rubric`: Evaluates code against the full 10-point Craft Rubric, returning letter grade (A+ to F), dimension scores, and SVG badge.
- `sloppy_plan_repairs`: Generates structured repair plan with confidence levels (high/medium/low), risk ratings, and AST-level repair items.
- `sloppy_autofix_code`: Automatically transforms sloppy AI code into clean craft, returning refactored code and detailed diff.
- `sloppy_get_archetype`: Retrieve any of the 10 multi-library synthesized master archetypes.
- `sloppy_search_components`: Search across 700+ components across all 7 libraries by query, library, or category.
- `sloppy_get_component`: Retrieve full source code (TSX/JSX), dependencies, and anti-slop craft guidance for any component ID.
- `sloppy_list_libraries`: List all 7 integrated UI libraries with descriptions, strengths, and specific anti-slop rules.
- `sloppy_list_catalog`: Inspect overall ecosystem statistics across components, libraries, looks, and patterns.
- `sloppy_audit_code`: Scan JSX/TSX/CSS files or snippets to detect AI slop with line numbers and severity scores.
- `sloppy_search_patterns`: Search 73+ curated gold patterns and real-product studies.
- `sloppy_get_pattern`: Fetch complete, runnable TSX code, scoped CSS, and motion choreography scripts.
- `sloppy_get_kit_primitives`: Retrieve ready-to-paste clean React/CSS primitives (`Stage`, `Window`, `Phone`, `Bento`, `Cursor`, `Act`, `Ease`, `Bar`, `Pill`, `Badge`).
- `sloppy_get_look`: Get design tokens, color scales, surface steps, border radii, and CSS variables for curated looks (`minimal`, `linear`, `radix`, `raycast`, `blueprint`, `glass`, `dark-hero`).
- `sloppy_get_rules`: Query detailed reference manuals (`craft`, `framing`, `motion`, `bento`, `word_budget`).
- `sloppy_refactor_slop`: Guided refactoring proposals.

## CLI Reference (`sloppy`)

```bash
# Evaluate code against 10-point Craft Rubric
sloppy rubric src/components/Hero.tsx --strict

# Generate a structured repair plan with confidence & risk analysis
sloppy plan src/components/Hero.tsx

# Surgically auto-fix code in-place
sloppy fix src/components/Hero.tsx --write

# Run browser geometric framing & motion continuity checks
sloppy verify http://127.0.0.1:1355

# Inspect or scaffold from 10 synthesized master archetypes
sloppy archetypes
sloppy create ai-agent-cockpit --dir ./src/components

# List all 7 integrated libraries and search components
sloppy libs
sloppy list magicui
sloppy list kokonutui

# Add a component directly into your project
sloppy add motion-primitives/morphing-dialog

# Launch the visual playground & Craft Studio on port 1355
sloppy dev
```

## 7-Step Anti-Slop Workflow

1. **Medium and Place**: Decide medium (still illustration or animated demo with cursor) and size (720x340 for hero beside copy, 960x480 for full-width hero, 440x320 for feature card). Design at 1:1 scale.
2. **Choose a Look**: Query `sloppy_get_look` for tokens (`linear`, `minimal`, `raycast`, `radix`, `blueprint`, `glass`, `dark-hero`).
3. **Select Foundations or Archetype**: Query `sloppy_search_components` or scaffold one of the 10 master archetypes via `sloppy create <archetype>`.
4. **Apply Word Budget**: Count the real strings (keep between 3 and 7). Use `<Bar />` for filler.
5. **Ground the Framing**: Windows and phones must cover >= 66% of the stage and bleed off at least one edge.
6. **Choreograph Caused Motion**: Use the `Act` API (`<Act on={clock} script={...}>`). Every motion must have a visible cause.
7. **Certify with Rubric**: Run `sloppy rubric <file>` to verify Grade A+ (>=95/100) before declaring completion.
