# Canonical Rule Table

Generated from `CANONICAL_RULES` in `packages/core/src/linter/types.ts` by
`npm run rules:sync`. The README table and the catalog title cells are generated
from the same table, so an ID has exactly one meaning everywhere.

- **Tier** is the enforcement gate: `floor` blocks, `reflex` needs a written rationale or cleanup, `finish` is advisory.
- **Mode** is honest about capability: `auto-fix` means `sloppy fix` rewrites it; `detect-only` means a human or agent must decide.
- **Slug and ID are interchangeable** in `sloppy-ignore`, `sloppy.config.json`, and `sloppy fix --only`.

## Auto-fix coverage

- `VIS-02` `PURPLE_GRADIENT_SLOP`
- `MED-02` `SPARKLE_ICON_OVERLOAD`
- `TYP-08` `WORD_BUDGET_EXCEEDED`
- `MOT-01` `UNEARNED_ANIMATION`

Everything else is **detect-only** on purpose: swapping a brand accent, rewriting
copy, or changing layout framing is a design decision, not a mechanical rewrite.

## Evidence & false-positive controls

Each rule declares the evidence it actually collects, how confident the detector
is, whether the finding is objective or a craft judgment, and when it must stay
quiet. `sloppy rules --json` exposes the same fields to agents.

### `AX-01` Inaccessible Fake Control
- **Family**: accessibility
- **Confidence**: high (objective defect)
- **Evidence collected**: source, standard
- **False positives**: The element receives role, tabIndex, and keyboard handling through spread props or a wrapper.
- **Not applicable when**: The clickable element is a documented third-party primitive.
- **Validation**: Verify accessible name, role, focus, and keyboard activation in the DOM.
- **Sources**: https://www.w3.org/WAI/WCAG22/Understanding/name-role-value.html, https://www.w3.org/WAI/WCAG22/Understanding/keyboard.html

### `COD-01` AI Narration Comment Slop
- **Family**: code
- **Confidence**: medium (craft judgment)
- **Evidence collected**: source
- **False positives**: The comment explains why an invariant exists, an edge case, or a tradeoff.
- **Not applicable when**: The file is generated code where comments are part of the output contract.
- **Validation**: Read the diff; never remove comments that carry non-obvious intent.
- **Auto-fix scope**: Only removes comments classified as narration by the heuristic; comments explaining intent are retained.

### `COD-02` Chained Type Assertion (as unknown as)
- **Family**: code
- **Confidence**: high (objective defect)
- **Evidence collected**: source
- **False positives**: The assertion is isolated in a documented adapter whose runtime validator is tested.
- **Not applicable when**: The value genuinely has an unknown boundary and is validated immediately.
- **Validation**: Run `tsc` and the relevant runtime test.

### `COD-03` Unvalidated Contract Return (any/unknown)
- **Family**: code
- **Confidence**: medium (craft judgment)
- **Evidence collected**: source
- **False positives**: The function is a generic utility with a documented caller-side validator.
- **Not applicable when**: The return type is intentionally unknown at a plugin boundary.
- **Validation**: Trace the value to its validator or add one.

### `COD-04` Broad Dictionary Type (Record<string, any>)
- **Family**: code
- **Confidence**: high (craft judgment)
- **Evidence collected**: source
- **False positives**: The dictionary is a short-lived boundary object validated by a schema.
- **Not applicable when**: The keys are genuinely unbounded and documented as such.
- **Validation**: Run `tsc`; prefer explicit keys or a bounded union.

### `COD-05` Conditional Empty Object Spread
- **Family**: code
- **Confidence**: medium (craft judgment)
- **Evidence collected**: source
- **False positives**: The conditional spread expresses a deliberate optional-prop merge.
- **Not applicable when**: The surrounding object is itself dynamic.
- **Validation**: Check that both branches produce a valid typed shape.

### `COD-06` Unsafe Chained Non-Null Assertion (!.)
- **Family**: code
- **Confidence**: high (objective defect)
- **Evidence collected**: source
- **False positives**: The invariant is established immediately above and covered by a test.
- **Not applicable when**: The value is guaranteed by an external contract with a runtime guard.
- **Validation**: Run the failure-path test; prefer optional chaining plus a guard.

### `CPY-01` Fabricated Social Proof Metrics
- **Family**: content
- **Confidence**: medium (craft judgment)
- **Evidence collected**: source
- **False positives**: Metrics with a verifiable source, date, and scope. Testimonials with attributable names and permission.
- **Not applicable when**: The number is a real product limit or documented benchmark.
- **Validation**: Ask for the source of any metric before replacing it; never invent a number.
- **Sources**: https://www.nngroup.com/articles/ten-usability-heuristics/

### `CPY-02` Unwired Pulsing Status Dots
- **Family**: content
- **Confidence**: medium (craft judgment)
- **Evidence collected**: source, interaction
- **False positives**: The dot is bound to a real health endpoint, status URL, or query result. A demo fixture explicitly labels itself as sample data.
- **Not applicable when**: No live-status claim is made in the surrounding copy.
- **Validation**: Verify the binding in the DOM/runtime, not only the class names.

### `CPY-03` Generic Marketing Clichés
- **Family**: content
- **Confidence**: medium (craft judgment)
- **Evidence collected**: source
- **False positives**: The phrase is literal domain terminology (for example "supercharge" in an energy product).
- **Not applicable when**: The copy is quoted from a real customer or source.
- **Validation**: Confirm the replacement states the concrete capability.

### `CPY-04` Negative Parallelism Cliché
- **Family**: content
- **Confidence**: high (craft judgment)
- **Evidence collected**: source
- **False positives**: A genuine before/after comparison or migration description.
- **Not applicable when**: The contrast is the product's actual value proposition and names both states.
- **Validation**: Read the rewritten sentence; it must stay truthful.

### `CPY-05` Em-Dash, Rule-of-Three & Filler Copy
- **Family**: content
- **Confidence**: low (craft judgment)
- **Evidence collected**: source
- **False positives**: Em dashes used intentionally and sparingly in editorial prose. A real range between two documented values.
- **Not applicable when**: The copy is legal, medical, or quoted text where punctuation is deliberate.
- **Validation**: Human review; these are style signals, not defects.

### `CPY-06` Chatbot Conversational Artifacts
- **Family**: content
- **Confidence**: high (craft judgment)
- **Evidence collected**: source
- **False positives**: The product is a chat interface and the text is part of the conversation.
- **Not applicable when**: The copy is a quoted assistant response inside a demo.
- **Validation**: Confirm the surrounding UI is product copy, not chat content.

### `CPY-07` Placeholder & Lorem Ipsum Copy
- **Family**: content
- **Confidence**: high (objective defect)
- **Evidence collected**: source
- **False positives**: The page is a documented specimen or design-system demo page.
- **Not applicable when**: The placeholder is explicitly labelled as sample content.
- **Validation**: Replace with domain nouns or an explicit placeholder state.

### `LAY-01` Center-Aligned Monotony
- **Family**: layout
- **Confidence**: medium (craft judgment)
- **Evidence collected**: source
- **False positives**: A centered hero or campaign page with deliberately limited content. Centered empty states and dialogs.
- **Not applicable when**: Centered text is a minority of layout elements and leading-edge anchors exist.
- **Validation**: Review the rendered page; centered composition may be the intended art direction.
- **Sources**: https://developer.apple.com/design/human-interface-guidelines

### `LIV-01` Sterile Surface & Missing Liveliness
- **Family**: visual
- **Confidence**: low (craft judgment)
- **Evidence collected**: human-review
- **False positives**: Intentional minimalism, brutalism, or editorial restraint with deliberate typography.
- **Not applicable when**: The surface is a utility screen where decoration would harm scanning.
- **Validation**: Human review only; do not auto-fix art direction.

### `MED-01` Raw Emojis as UI Icons
- **Family**: visual
- **Confidence**: high (craft judgment)
- **Evidence collected**: source
- **False positives**: Emoji is actual content (chat message, user-generated text).
- **Not applicable when**: Emoji appears in a code sample or documentation string.
- **Validation**: Replace only UI chrome; leave user content untouched.

### `MED-02` Sparkle / Magic-Wand Icon Overload
- **Family**: visual
- **Confidence**: high (craft judgment)
- **Evidence collected**: source
- **False positives**: Sparkle is the product domain (for example a generation action that literally creates sparkles). The icon is decorative inside an illustration, not attached to a generic action.
- **Not applicable when**: The icon communicates a documented AI capability the product actually provides.
- **Validation**: Confirm the replacement icon names the action rather than inventing a metaphor.

### `MOT-01` Unearned Looping Animation
- **Family**: motion
- **Confidence**: high (craft judgment)
- **Evidence collected**: source
- **False positives**: Loading spinners and progress indicators that communicate real progress. Motion that is triggered by a user action and settles.
- **Not applicable when**: The animation is the only way the product communicates an asynchronous state.
- **Validation**: Check `prefers-reduced-motion` and confirm a non-motion state cue exists.
- **Sources**: https://developer.apple.com/design/human-interface-guidelines/motion

### `MOT-02` Unbounded Infinite Programmatic Motion
- **Family**: motion
- **Confidence**: high (craft judgment)
- **Evidence collected**: source
- **False positives**: Explicit loading spinners, progress indicators, or subtle ambient canvases gated by reduced motion.
- **Not applicable when**: The infinite loop lives inside a verified spinner or user-paused playback widget.
- **Validation**: Replace `repeat: Infinity` or `loop: true` with a finite caused settle or add an explicit spinner/reduced-motion guard.
- **Sources**: https://developer.apple.com/design/human-interface-guidelines/motion

### `MOT-03` Missing Reduced-Motion Guard
- **Family**: motion
- **Confidence**: high (objective defect)
- **Evidence collected**: source, standard
- **False positives**: Reduced-motion handling is centralized in a root `<MotionConfig reducedMotion="user">` provider outside this file.
- **Not applicable when**: The file only wraps or exports static types without executing runtime animations or render loops.
- **Validation**: Verify `prefers-reduced-motion: reduce` disables or simplifies movement in the browser.
- **Sources**: https://www.w3.org/WAI/WCAG22/Understanding/animation-from-interactions.html

### `MOT-04` Layout-Thrashing Property Animation
- **Family**: motion
- **Confidence**: medium (objective defect)
- **Evidence collected**: source
- **False positives**: Accordion height reveals (`height: "auto"`) bounded by `overflow-hidden`.
- **Not applicable when**: The animation is handled via CSS transforms (`x`, `y`, `scale`) and `opacity`.
- **Validation**: Inspect browser performance flamecharts and swap geometry properties for `transform` and `opacity`.

### `MOT-05` Unmanaged WebGL, Lottie, or Scroll Loop
- **Family**: motion
- **Confidence**: high (objective defect)
- **Evidence collected**: source
- **False positives**: Cleanup or throttling is managed by a parent controller or custom hook outside this component.
- **Not applicable when**: The file creates a one-shot static export rather than a mounted browser render loop.
- **Validation**: Confirm `.dispose()`/`.destroy()` runs on unmount and `<Canvas>` specifies `frameloop="demand"` or capped `dpr`.

### `MOT-06` Cross-Property Transition Slop (transition: all)
- **Family**: motion
- **Confidence**: high (craft judgment)
- **Evidence collected**: source
- **False positives**: A deliberate cross-property transition on a single known state swap (for example a theme toggle that must move color and border together).
- **Not applicable when**: The element transitions exactly one named property through an explicit property list.
- **Validation**: Replace `transition-all` / `transition: all` with an explicit property list, then confirm hover, focus, and active states still animate.
- **Sources**: https://developer.chrome.com/docs/modern-web-guidance/guides/ui-behaviors/motion

### `MOT-07` Slow Interaction Feedback
- **Family**: motion
- **Confidence**: medium (craft judgment)
- **Evidence collected**: source
- **False positives**: Storytelling or demo motion, which is allowed to run longer than product feedback.
- **Not applicable when**: The element is a page-level surface (sheet, drawer, full-screen menu) where 300-400ms reads as lighter, not sluggish.
- **Validation**: Time the hover, press, and state change at normal speed; direct feedback should start immediately and settle inside ~300ms.
- **Sources**: https://emilkowal.ski/ui/great-animations

### `MOT-08` Scroll-Reveal Saturation
- **Family**: motion
- **Confidence**: medium (craft judgment)
- **Evidence collected**: source
- **False positives**: A single deliberate reveal on the one section that earns it, with content rendered and readable before JavaScript runs.
- **Not applicable when**: The page needs scroll-linked storytelling and states that in its design contract.
- **Validation**: Disable JavaScript and load with throttling: first-screen content must be present and legible; keep at most one scroll-reveal motif.
- **Sources**: https://developer.chrome.com/docs/modern-web-guidance/guides/ui-behaviors/motion

### `MOT-09` Autoplay Motion Without Pause Control
- **Family**: motion
- **Confidence**: high (objective defect)
- **Evidence collected**: source, standard
- **False positives**: Decorative motion that runs under five seconds, or a loader that communicates real progress.
- **Not applicable when**: The marquee or carousel pauses when hovered/focused and offers no motion under `prefers-reduced-motion: reduce`.
- **Validation**: Add a visible keyboard-operable pause control, or make the motion finite. Verify under WCAG 2.2.2 Pause, Stop, Hide.
- **Sources**: https://www.w3.org/WAI/WCAG22/Understanding/pause-stop-hide.html

### `MOT-10` Flashing or Strobe Animation
- **Family**: motion
- **Confidence**: high (objective defect)
- **Evidence collected**: source, standard
- **False positives**: A single non-repeating flash used as a screenshot or shutter affordance.
- **Not applicable when**: Nothing flashes more than three times in any one-second period.
- **Validation**: Remove the flash, or reduce it below three flashes per second; verify with a slow-motion capture.
- **Sources**: https://www.w3.org/WAI/WCAG22/Understanding/three-flashes-or-below-threshold.html

### `MOT-11` Entrance From scale(0)
- **Family**: motion
- **Confidence**: medium (craft judgment)
- **Evidence collected**: source
- **False positives**: A spring gesture that legitimately collapses an object to zero while the finger holds it.
- **Not applicable when**: The element is a loader or icon drawing, not an entering surface.
- **Validation**: Start the entrance at 0.9-0.96 scale instead of 0 and check the first frame reads as a shape, not a pop-in.
- **Sources**: https://emilkowal.ski/ui/7-practical-animation-tips

### `MOT-12` CSS Loop Without Reduced-Motion Guard
- **Family**: motion
- **Confidence**: medium (craft judgment)
- **Evidence collected**: source, standard
- **False positives**: Reduced-motion handling lives in a global stylesheet or provider outside this file.
- **Not applicable when**: The animation is a progress affordance that communicates real asynchronous state.
- **Validation**: Add `@media (prefers-reduced-motion: reduce)` (or `motion-safe:`) and confirm the loop stops or simplifies in the browser.
- **Sources**: https://www.w3.org/WAI/WCAG22/Understanding/animation-from-interactions.html

### `MOT-13` Vestibular-Risk Parallax or 3D Tilt
- **Family**: motion
- **Confidence**: medium (craft judgment)
- **Evidence collected**: source, standard
- **False positives**: Parallax confined to a small decorative accent that stops under reduced motion.
- **Not applicable when**: The 3D tilt is a direct manipulation preview the user actively drags, not an ambient hover effect.
- **Validation**: Guard full-viewport parallax, tilt, and zoom with reduced motion and keep the moving area small; WCAG 2.3.3 Animation from Interactions applies.
- **Sources**: https://www.w3.org/WAI/WCAG22/Understanding/animation-from-interactions.html

### `MOT-14` Hover Motion on a Non-Interactive Surface
- **Family**: motion
- **Confidence**: high (craft judgment)
- **Evidence collected**: source
- **False positives**: The lifted surface is itself the click target (`<a>`, `<button>`, or a row with a real handler).
- **Not applicable when**: The lift communicates a draggable object during an active drag, not on idle hover.
- **Validation**: Remove hover lift from static surfaces; if the card is interactive, make the whole card the semantic control and keep the lift subtle.
- **Sources**: https://emilkowal.ski/ui/great-animations

### `MOT-15` Uniform Entrance Motion
- **Family**: motion
- **Confidence**: medium (craft judgment)
- **Evidence collected**: source
- **False positives**: A single intentional entrance on the one focal element of the view. A genuinely staggered sequence whose order follows reading order and whose items differ in job.
- **Not applicable when**: The page is a storytelling demo where the same object arrives once per scene.
- **Validation**: Count distinct elements sharing the same initial+animate pair; four or more is the uniformity tell. Render first-screen text without motion and keep one restrained reveal.
- **Sources**: https://github.com/kylezantos/design-motion-principles/blob/main/skills/design-motion-principles/references/anti-checklist.md, https://www.paralect.com/blog/signs-of-ai-slop-in-design

### `MOT-16` Overshoot/Elastic Easing on UI Motion
- **Family**: motion
- **Confidence**: medium (craft judgment)
- **Evidence collected**: source
- **False positives**: An overshoot reserved for one small expressive icon or a direct-manipulation gesture. A spring the user actively drags, not an idle hover or a routine dialog entrance.
- **Not applicable when**: The element is a playful brand moment whose overshoot is declared in the design contract.
- **Validation**: Watch the entrance at 10-25% speed; a dialog or card that bounces should settle on ease-out instead.
- **Sources**: https://impeccable.style/slop, https://emilkowal.ski/ui/7-practical-animation-tips

### `MOT-17` Permanent will-change Layer Hint
- **Family**: motion
- **Confidence**: medium (craft judgment)
- **Evidence collected**: source
- **False positives**: A single `will-change` set by an animation hook just before a known transition and cleared after.
- **Not applicable when**: The file declares one layer hint on a canvas or video surface that animates continuously.
- **Validation**: Remove the hint at rest; measure layers and memory in devtools if the page keeps it on many elements.

### `MOT-18` Off-Contract Motion Duration
- **Family**: motion
- **Confidence**: medium (craft judgment)
